# 协议设计文档

## 概述

本文档定义客户端与服务端之间的通信协议。

## 协议格式

### 请求格式

```
[消息头][消息体]

消息头：
- 版本号 (1 byte)
- 消息类型 (2 bytes)
- 消息长度 (4 bytes)

消息体：
- JSON格式的业务数据
```

### 响应格式

```
[消息头][响应状态][消息体]

响应状态：
- 状态码 (2 bytes)
- 错误信息长度 (2 bytes)
- 错误信息 (可选)
```

## 消息类型定义

| 类型值 | 名称 | 说明 |
|-------|------|------|
| 0x01 | LOGIN | 用户登录 |
| 0x02 | LOGOUT | 用户登出 |
| 0x03 | GET_STATUS | 获取行车状态 |
| 0x04 | START_RECORD | 开始行车记录 |
| 0x05 | STOP_RECORD | 结束行车记录 |
| 0x06 | GET_WARNINGS | 获取报警信息 |
