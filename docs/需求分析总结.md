# 360度智能行车辅助系统 - 需求分析总结

## 核心功能概览

### 一、客户端功能模块

#### 1. 用户登录注册系统
- 开机动画展示
- 用户注册（账号6-8位，密码6-10位，MD5加密）
- 用户登录验证
- 验证码验证（字母+数字）

#### 2. 系统设置
- 配置服务器IP地址和端口
- 配置本地视频存储大小
- 满数据时自动删除旧视频
- 配置保存到文件，下次自动加载

#### 3. 实时视频模式（核心功能）
**行车模式**：
- 前后左右2-4个摄像头实时采集
- 图像畸变还原
- 视角转化
- 图像拼接
- 图像增强
- 实时视频展示 + 水印添加

**鸟瞰模式**：
- 360度全景鸟瞰图展示
- 无缝完整的车周全景图
- 配合标尺线读取障碍物位置和距离

**倒车模式**：
- 倒车实时视频展示
- 障碍物自动提醒功能

**红绿灯检测**：
- 实时检测红绿灯
- 图像识别算法（OpenCV）

#### 4. 视频数据管理
- 视频数据列表展示
- 历史播放信息记录
- 播放时长、地点等信息
- 场景重现（播放本地视频）

#### 5. 特征数据管理
- 特征图片列表展示
- 障碍物图片自动上传
- 手动上传当前图片数据
- 视频播放记录上传

### 二、服务器端功能模块

#### 1. 接入服务器（前置服务器）
- 客户端连接管理
- 心跳处理（定时检测，超时断开）
- 并发负载（30个初始线程，最多200个）
- 实时日志（客户端连接情况、业务请求）

#### 2. 业务服务器（后置服务器）
- 用户登录注册业务处理
- 各类型业务请求处理
- 数据库操作（SQLite或MySQL）
- 全部日志（写入文本文件）

#### 3. 数据库设计
- 用户信息表（用户名、密码MD5、权限）
- 视频记录表（文件名、时间、地点、播放信息）
- 特征图片表（障碍物图片、上传时间）
- 播放记录表（用户ID、视频ID、播放时长）

### 三、压力测试程序
- 参数配置（并发数、测试时长）
- 业务测试（模拟客户端请求）
- 日志信息（实时日志）
- 测试报告（性能数据）

## 技术栈分析

### 原需求文档提到的技术
- Socket网络通讯（TCP/IP）
- OpenCV图像处理（畸变还原、拼接、增强）
- Qt界面编程
- 多进程/多线程技术
- 进程间通信（IPC：信号、管道、消息队列、共享内存）
- 线程同步（信号量、互斥、条件变量）
- SQLite数据库或MySQL
- 自定义协议结构
- 大并发服务器架构
- FFMpeg（视频处理）

### 用户升级的技术栈
- **FDBus**（替代Socket，高性能IPC，零拷贝）
- **MySQL**（替代SQLite，更强大的数据库）
- **Qt MVVM架构**（更规范的界面架构）

## 核心挑战

### 1. 实时视频处理（最关键）
- **挑战**：4个摄像头实时采集，图像处理，拼接展示
- **方案**：使用FDBus零拷贝传输图像数据，减少内存拷贝开销
- **技术**：OpenCV图像处理算法 + FDBus高性能IPC

### 2. 大并发通信
- **挑战**：30个初始线程，最多200个线程并发处理
- **方案**：FDBus支持大并发，配合线程池管理
- **技术**：FDBus + 线程池 + 连接管理

### 3. 图像识别算法
- **挑战**：红绿灯检测、障碍物检测
- **方案**：OpenCV通用算法（颜色识别、轮廓检测）
- **技术**：OpenCV + 特征提取算法

## 关键技术点

### FDBus零拷贝优势
- **传统Socket**：数据需要多次拷贝（用户空间→内核空间→用户空间）
- **FDBus零拷贝**：共享内存直接传输，减少拷贝开销
- **性能提升**：适合大图像数据传输（摄像头图像）

### OpenCV图像处理流程
1. 图像采集（摄像头）
2. 畸变还原（去除摄像头畸变）
3. 视角转化（转换为俯视图等）
4. 图像拼接（拼接成全景图）
5. 图像增强（提高图像质量）
6. 红绿灯检测（颜色识别）
7. 障碍物检测（轮廓识别）
